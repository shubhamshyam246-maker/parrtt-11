# Automobile Sales Statistics Dashboard

Interactive Dash app analyzing historical automobile sales during recession and non-recession periods.

## Run
1. `pip install -r requirements.txt`
2. `python automobile_sales_dashboard.py`
3. Open http://127.0.0.1:8050/

## Features
- **Yearly Statistics**: sales trend, monthly sales, average sales by vehicle type, and ad spend share for a selected year
- **Recession Period Statistics**: sales trend, average sales by vehicle type, ad spend share, and unemployment-rate effect during recessions
